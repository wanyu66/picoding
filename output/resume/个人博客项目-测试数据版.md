# 个人博客项目：简历替换文案

技术栈：Java 8、Spring Boot、MyBatis-Plus、MySQL、Redis、Elasticsearch、RabbitMQ、WebSocket/STOMP。

项目简介：基于 Spring Boot 的技术内容社区，支持文章发布、评论互动、全文检索与 AI 对话；重点实现列表查询优化、异步事件处理、缓存故障回退及 AI 流式交互可靠性。

- **列表查询优化：** 将标签、作者逐篇查询改为批量补全，结合作者去重与 Redis Pipeline 读取统计；在 8 篇同作者、暖缓存的对照测试中，单页 SQL 从 33 次降至 4 次，减少 87.9%，Redis 连接获取从 16 次降至 2 次。
- **异步事件与排行榜：** 基于 Transactional Outbox、RabbitMQ 消费幂等和 Redis ZSet/Lua 实现积分更新与失败补偿；以 1,000 个事件各投递 3 次、8/32 并发验证，在有序混合及 RabbitMQ 中断、提交后 ACK 前退出、Redis 补偿场景中，重复积分副作用及日/月榜积分偏差均为 0。
- **AI 流式可靠性：** 修复提前断流误判、重复持久化及取消竞态，增加跨模型总超时与总尝试次数限制；14 项模拟故障及回归场景通过，重复结束仅写入 1 条测试记录，102 次取消检查无漏执行，模拟上游在取消后 63 ms 确认连接关闭。
- **文章检索与评测：** 实现字段权重、拼音与容错召回、热度及时间衰减排序；构建覆盖中文、拼音、错拼、同义词与无答案候选的 64 条查询试评集，完成三版本共 192 次离线 ES 查询，提供人工相关性标注与指标计算工具。

## 面试时必须保留的测试口径

1. SQL 降幅为确定性夹具对照结果，不是线上时延或 QPS 提升；8 篇不同作者时 Redis 连接获取为 9 次，不能套用 2 次。基于 H2、生产 Mapper/DAO 和可控 RedisConnection。
2. Outbox 共 10 项用例，8 项通过、2 项乱序取消用例失败；取消先于点赞时日/月榜各有 800 分绝对偏差，尚未修复。不能宣称全场景最终一致性。通过场景使用隔离的真实 MySQL、RabbitMQ、Redis。
3. AI 测试使用真实 HTTP/SSE、生产解析器和业务模板，以及隔离 MySQL SQL sink；不是整站 STOMP 与正式历史 DAO 的端到端验收。取消计时从服务端 cancel 调用开始，到模拟上游观察到断开，不能写成真实模型响应时延。
4. 350 ms 路由总预算实测 363 ms，包含调度和记录开销；总尝试次数设为 3 时实际调用 3 次。默认配置为 40 秒、4 次，350 ms 是测试配置。
5. 搜索语料仅 8 篇真实文章，512 对相关性标签尚未完成人工标注；不能声称准确率、Recall、MRR 或 NDCG 提升。查询由助手按语料编写，不是用户搜索日志。
6. 数据来自 2026 年 9 月测试，原简历项目日期为 2026/01–2026/05；日期应按实际情况更新或注明后续迭代，不应将 9 月结果写成 5 月验收。
